## REGRESSION BUG FIX SUMMARY

**Bug**: Inverted validation logic preventing valid inputs from being processed

**Location**: `src/knapsack_solver.py` line 31

**Original Code**:
```python
if any(w > 0 for w in weights):  # WRONG - rejects all valid inputs
    return 0
```

**Fixed Code**:
```python
if any(w <= 0 for w in weights):  # CORRECT - only rejects invalid inputs
    return 0
```

**Result**: ✅ All tests now pass (was 2/7, now 7/7)
